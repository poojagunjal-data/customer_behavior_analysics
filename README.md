# Customer Trends Data Analysis (SQL, Python & Power BI)

## Project Overview

This project focuses on analyzing customer shopping trends to uncover valuable business insights related to purchasing behavior, customer preferences, sales patterns, and product performance. The analysis was performed using SQL, Python, and Power BI to transform raw customer data into actionable insights.

The project demonstrates end-to-end data analysis skills, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and dashboard creation.

---

## Objectives

* Analyze customer purchasing behavior.
* Identify top-performing product categories and items.
* Segment customers based on purchase history.
* Understand the impact of discounts, subscriptions, and seasonal trends.
* Generate business recommendations through data-driven insights.

The dataset contains customer transaction details, including:

* Customer ID
* Age
* Gender
* Category
* Item Purchased
* Purchase Amount
* Previous Purchases
* Subscription Status
* Discount Applied
* Payment Method
* Frequency of Purchases
* Shipping Type
* Season

## Key Insights

* Loyal customers contribute significantly to total purchases.
* Certain product categories consistently outperform others.
* Discounts positively influence purchasing behavior.
* Seasonal trends impact customer spending patterns.
* Returning customers represent a substantial portion of the customer base.
* Customer segmentation helps identify retention opportunities.
